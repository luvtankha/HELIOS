# Changelog

This project was developed in numbered phases; dates are intentionally omitted where release history is not independently established.

- **Phases 0–4:** monorepo/API/data foundations, consented patient flow, browser voice/provider abstraction, adaptive deterministic interview and clinical NLU boundary.
- **Phases 5–12:** Phase 5 SafetyEngine remains not implemented; document AI, longitudinal timeline, deterministic What Changed, source-linked Clinical Brief, doctor verification, neutral AYUSH capture, and English/Hindi language layer were implemented in prototype scope.
- **Phases 13–14:** separate doctor routes/workspace, assignment-aware backend access, notes/visit transitions, daily queue/token lifecycle and polling waiting experience.
- **Phases 15–17:** security assessment, attack regression and production locks; these are engineering controls, not certification or production approval.
- **Phases 18–19:** UI polish and broad QA; Phase 19 records the measured suites and open release blockers.
- **Phase 20:** isolated synthetic SIH entry, golden-patient presenter paths and scripts.
- **Phase 21:** doctor-authorized demo reset, strict demo-state validation, client refresh signal, audit and production-block/concurrency/failure tests.
- **Phase 22:** current-code documentation index, architecture/product/flow/API/database/provider/operations/demo/SIH/contributor guides; stale README/demo/AI statements corrected.

See [documentation index](docs/README.md) and [limitations](docs/limitations.md).
