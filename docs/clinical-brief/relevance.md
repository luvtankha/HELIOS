# Deterministic relevance

Ordering favors current reason, existing safety attention, recent changes, unresolved verification, current symptoms, medications, allergies, investigations, history, and documents. Configurable environment values define the recent window and maximum symptoms, changes, and documents.

Current structured visit records are used; raw transcripts and historical document text are not reconstructed. Recent document and observation queries are bounded. Persistent allergies remain eligible outside the recent window. A stable claim key prevents accidental duplicate claims.
