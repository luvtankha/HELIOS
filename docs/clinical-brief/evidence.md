# Evidence behavior

The claim endpoint validates that the claim belongs to the requested brief. The UI evidence drawer shows source label, date, page, excerpt, structured value, and source identifier. Comparison claims preserve previous/current Phase 8 evidence; document claims retain Phase 6 fact/page excerpts; historical claims retain Phase 7 event references.

Full binary document rendering remains the existing Phase 6 viewer’s responsibility. Phase 9 does not create another OCR or document-preview implementation.
