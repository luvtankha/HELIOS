# Configuration and environment profiles

The API validates configuration in [`apps/api/src/config/env.ts`](../apps/api/src/config/env.ts). Root wrappers read an ignored `.env`; templates never provision PostgreSQL. Never commit `.env` or put secrets in `NEXT_PUBLIC_*`.

Speech now supports `SPEECH_PROVIDER=local` (the example-profile selection), `openai`, or explicit `mock`. Local recognition requires `pnpm speech:setup`; optional `SPEECH_LOCAL_PYTHON`, `SPEECH_LOCAL_MODEL_PATH`, and `SPEECH_LOCAL_TIMEOUT_MS` configure its worker. No speech API key is needed locally. See [voice setup](voice.md). The active local installation also uses `DOCUMENT_OCR_PROVIDER=local`; OCR templates retain their previous values.

| Variable(s)                                                                                                                       | Purpose                                                                          | Profile                                     |
| --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------- |
| `NODE_ENV`, `PORT`, `LOG_LEVEL`                                                                                                   | Runtime mode, API port, Pino level                                               | All                                         |
| `DATABASE_URL`                                                                                                                    | Provisioned PostgreSQL URL                                                       | Database flows; secret                      |
| `WEB_ORIGIN`, `NEXT_PUBLIC_API_URL`                                                                                               | Allowed browser origin and public API base                                       | All; API URL is public                      |
| `SESSION_TOKEN_SECRET`, `PATIENT_SESSION_TTL_SECONDS`, `DOCTOR_SESSION_TTL_SECONDS`                                               | HMAC key and proof lifetimes                                                     | All; secret must be replaced                |
| `ENABLE_DEMO_MODE`, `DEMO_MODE`, `NEXT_PUBLIC_DEMO_MODE`, `ALLOW_DEMO_SEED`                                                       | Server demo gate, application demo gate, route visibility, destructive seed gate | False normally; demo wrapper forces true    |
| `DOCTOR_DEMO_ACCESS_CODE`                                                                                                         | Synthetic doctor login                                                           | Demo only; not production identity          |
| `STORAGE_PROVIDER`, `STORAGE_PATH`                                                                                                | `local` private document storage                                                 | Documents; never under public web assets    |
| `ENABLE_VOICE`, `SPEECH_PROVIDER`, `SPEECH_API_KEY`, `SPEECH_MODEL`, `SPEECH_TIMEOUT_MS`                                          | Voice feature and mock/OpenAI STT adapter                                        | Key only for OpenAI                         |
| `VOICE_MAX_DURATION_SECONDS`, `VOICE_MAX_FILE_BYTES`                                                                              | Server upload bounds                                                             | Voice                                       |
| matching `NEXT_PUBLIC_VOICE_*`                                                                                                    | Browser UX bounds                                                                | Public; not security controls               |
| `ENABLE_AI_INTERVIEW`, `CLINICAL_NLU_PROVIDER`, `AI_API_KEY`, `AI_MODEL`, `AI_TIMEOUT_MS`                                         | Rules/default or optional OpenAI NLU                                             | Key only for OpenAI                         |
| `ENABLE_OCR`, `DOCUMENT_OCR_PROVIDER`, `DOCUMENT_MAX_FILE_BYTES`, `DOCUMENT_PROCESSING_TIMEOUT_MS`, `DOCUMENT_PROCESSING_VERSION` | Mock/local OCR and processing bounds/version                                     | Documents                                   |
| `ENABLE_AYUSH`                                                                                                                    | AYUSH capture feature                                                            | Explicit profile choice                     |
| `ENABLE_SPECIALIZATION_ROUTING`                                                                                                   | Optional deterministic intake department routing and provider preference          | Explicit profile choice; false by default  |
| `ENABLE_RISK_ENGINE`                                                                                                              | Reserved flag                                                                    | Does not implement the missing SafetyEngine |
| `BRIEF_RECENT_MONTHS`, `BRIEF_MAX_*`                                                                                              | Deterministic brief limits                                                       | Doctor brief                                |
| `TEST_DATABASE_URL`                                                                                                               | Local DB/schema beginning `helios_test`                                          | Integration tests only                      |
| `TEST_LOAD_URL`                                                                                                                   | Explicit local load-smoke target                                                 | Testing only                                |

Use [`.env.example`](../.env.example) for ordinary development, [`.env.sih-demo.example`](../.env.sih-demo.example) for synthetic demo, and [`.env.test.example`](../.env.test.example) for tests. `AI_PROVIDER` is not used; select NLU with `CLINICAL_NLU_PROVIDER`. Production startup rejects built-in secrets, enabled demo mode, the default demo code, and a public storage path, but that is not production certification.
