# Safety boundary

Phase 11 never creates `RiskSignal`. It only exposes structured AYUSH facts as potential future inputs to the Phase 5 boundary. An existing, non-demo signal is shown only when its stored category/title/description explicitly concerns AYUSH, traditional, or concurrent treatment use.

Concurrent conventional medication and AYUSH use is described as concurrent use. If no relevant stored signal exists, the UI says interaction information is unavailable; it does not claim safety or interaction. Verification of an AYUSH fact does not acknowledge, dismiss, resolve, or otherwise mutate a signal.

This checkout contains RiskSignal persistence but no executable SafetyEngine or authoritative interaction rule source.
