# Timeline integration

AyushRecords project into the existing Timeline as `AYUSH_TREATMENT`. Start and end dates remain treatment dates; recording and doctor-verification dates remain separate events. Current, historical, stopped, and unknown map respectively to current, historical, discontinued, and unknown temporal states.

Reported effects use “reported after treatment use.” Timeline generation never changes temporal association into causation. Rebuild derives the event from the source record and preserves version history through the existing fingerprint/version mechanism.
