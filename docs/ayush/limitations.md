# Limitations

HELIOS captures and organizes AYUSH information. It does not independently prescribe AYUSH treatment, diagnose using AYUSH concepts, infer treatment efficacy, infer causality from temporal association, validate practitioner registration, or replace qualified healthcare professionals.

Interaction information requires validated rules or authoritative sources. None is implemented here. Phase 5 has storage only, so Phase 11 does not synthesize a safety demonstration. Ingredient lists are present only when explicitly documented.

Production limitations inherited from the repository include demo HMAC clinician authentication, no organization/care-team assignment model, local document storage, no persisted voice audio, and no configured live database in the current environment.
