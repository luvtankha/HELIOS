# Clinical Brief integration

The existing Clinical Brief gains the optional `AYUSH / other healthcare use` section. Each concise claim shows system, original/normalized documented name, current/historical state, documented dose/frequency, reported reason/effect, source, and verification state.

Rejected/superseded records are excluded. Unverified items are marked as needing verification. Reported effects use temporal wording only. The generator revision includes AYUSH inputs, and a mutation marks active briefs stale.
