# Document AI evaluation

Tests under `apps/api/tests/document-ai/` cover all four document classifications plus unknown; medication and lab extraction; explicit-diagnosis boundaries; absence of inferred allergy; OCR error preservation; confidence; mock OCR layout; MIME signatures; traversal-safe private storage; duplicate detection; patient mismatch; safety eligibility; asynchronous APIs; correction; rejection; private content headers; and soft removal.

Synthetic binary fixtures are generated by `pnpm document-fixtures:generate` under `dataset/documents/phase6-fixtures/`. The 11 files cover clean digital PDF, lab PNG, two-page discharge PDF, degraded scan, rotated image, handwritten-like note, ambiguous OCR, missing date, multiple medications, multiple lab values, and a byte-identical duplicate.

## Metrics

- Field precision = correct extracted fields / all extracted fields.
- Field recall = correct extracted fields / expected explicit fields.
- Exact match applies to medicine name, numeric dose/result, unit, frequency, and supported ISO dates.
- Evidence coverage = important extracted facts with source text / important extracted facts.
- Review routing measures low-confidence/mismatch facts routed to review.

These metrics evaluate deterministic synthetic fixtures only. They are not clinical-performance, OCR-quality, population, or medical-device claims.
