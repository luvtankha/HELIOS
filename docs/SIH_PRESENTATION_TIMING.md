# HELIOS — presentation timing cards

These are **rehearsal targets**, not measured speaking or demo durations. Confirm the event limit and leave time for judge questions. Do not attempt a full browser journey when the clock or service state makes it unreliable.

| Format | Talk | Live demo | Close / question buffer | Priority |
| - | - | - | - | - |
| 3 minutes | 0:00–0:45 problem + positioning | 0:45–2:35 text intake → token → authorized doctor evidence/verification; use preseeded Aarav for longitudinal view, disclosed | 2:35–3:00 clinical boundary + close | No slide tour; one journey |
| 5 minutes | 0:00–1:30 slides 1, 2, 4, 9 | 1:30–4:20 compressed live journey | 4:20–5:00 now/next + close | Demonstration over technology inventory |
| 8 minutes | 0:00–2:30 slides 1–9 (selective) | 2:30–6:30 live journey | 6:30–8:00 architecture/security/now-next/close | One evidence and verification action |
| 10 minutes | 0:00–3:30 slides 1–15, moving quickly | 3:30–8:15 live journey | 8:15–10:00 now/next, questions, close | Do not read every slide |

## Presenter cues

- Open with the exact line: **“Turn patient waiting time into clinical intelligence.”**
- Show consent and typed Hindi first; describe speech as optional unless it is actually functioning live.
- Distinguish a newly created token from Aarav’s seeded A-001.
- Give the clinical boundary its own sentence: the SafetyEngine is **not implemented**; no diagnosis or treatment claims.
- Close with: **“HELIOS doesn't replace the doctor. It gives the doctor a clearer story, before the consultation begins.”** Then repeat the positioning line.

The [30-second](SIH_30_SECOND_PITCH.md), [60-second](SIH_60_SECOND_PITCH.md) and [three-minute](SIH_3_MINUTE_PITCH.md) scripts are alternatives, not additional material to recite before the timed demo.
