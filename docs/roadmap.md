# Roadmap

## Implemented prototype scope

Consent-first patient intake, English/Hindi text UI, browser recording with provider abstraction, deterministic interview, private documents with mock/local OCR, provenance, timeline, What Changed, Clinical Brief, doctor verification, AYUSH capture, separate doctor route tree, daily queue/token workflow, synthetic SIH demo, and guarded deterministic reset.

## Next (required before claiming a complete SIH/clinical system)

Clinician-designed/versioned/tested SafetyEngine; complete all-browser demo rehearsal; production clinician identity/assignment policy; retention/withdrawal/deletion; deployment threat model and infrastructure validation; broader document/language/provider evaluation; distributed controls and audit integrity; backup/restore drills.

## Future (not committed implementation)

Additional languages and speech evaluation, production object storage/queues/monitoring, standards-based ABDM/FHIR interoperability, clinic tenancy, additional document formats, external clinical integrations, and formal clinical/regulatory studies. These are possibilities, not existing features or delivery promises.
