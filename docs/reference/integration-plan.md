# Reference integration plan

| Change                        | Why                                                        | Source of inspiration                      | HELIOS implementation                                                          | Risk                                                                   | Priority                  |
| ----------------------------- | ---------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------- | ------------------------- |
| Add typed Observation         | Labs/vitals need typed, time-bound values                  | OpenMRS Obs; OpenEMR/Synthea Observation   | Prisma entity with concept key/code/value/unit/range/effective time/provenance | Generic records can become a dumping ground; require schema validation | P0 implemented            |
| Extend provenance             | Document/system facts must not masquerade as patient facts | FHIR Provenance; EHR audit patterns        | Add `DOCUMENT_EXTRACTED`, `SYSTEM_GENERATED`                                   | Existing clients must accept new enum members                          | P0 implemented            |
| Add NOT_APPLICABLE            | Unknown and irrelevant are different                       | OpenMRS null/void semantics; dataset needs | Shared/Persistence KnowledgeState                                              | Misuse could hide missing data                                         | P0 implemented            |
| Extend verification outcomes  | Partial correctness and omissions differ from edits         | Dialogue/document evaluation patterns      | Add `PARTIALLY_CORRECT` and `MISSED` without collapsing existing outcomes      | Review UI must explain the distinctions                                | P0 implemented            |
| Version interview graph       | Reproducible evaluation and resume                         | Metadata/version concepts                  | `questionGraphVersion` on Interview                                            | Migration/default coordination                                         | P0 implemented            |
| Original seeded generator     | Repeatable longitudinal test corpus                        | Synthea approach                           | Node generator using HELIOS templates, not Synthea records                     | Synthetic bias mistaken for prevalence                                 | P0 implemented            |
| Leakage-safe split            | Honest evaluation                                          | ML dataset practice                        | Patient-level deterministic assignment                                         | Future augmentation must preserve grouping                             | P0 implemented            |
| FHIR mapping layer            | Future interoperability without domain replacement         | OpenEMR/OpenMRS/Synthea FHIR               | Documentation plus fixture export                                              | Mapping can be mistaken for conformance                                | P1 reference only         |
| Concept catalog               | Multilingual synonyms and external codes                   | OpenMRS Concept                            | Small curated, reviewed catalog later                                          | Clinical governance and terminology licensing                          | P1 planned                |
| Section-aware note evaluation | Detect omissions/hallucinations                            | MTS-Dialog                                 | Benchmark expected structured history by section                               | Text metrics alone are misleading                                      | P1 dataset implemented    |
| Indic audio benchmark         | Measure ASR and semantic loss per language                 | Indic speech layout                        | Separate licensed audio manifest and derived metrics later                     | Current reference is tiny and unsegmented                              | P1 planned                |
| Document extraction pipeline  | Future Phase 6 evaluation                                  | OpenEMR documents + synthetic exports      | Synthetic documents with expected entities/difficulty                          | OCR realism and clinical validation                                    | P1 dataset implemented    |
| Timeline delta engine         | Identify new/removed/changed facts                         | Longitudinal EHR/Synthea                   | Evaluation fixtures now; production service later                              | Temporal and identity matching errors                                  | P2 planned                |
| Safety engine                 | Risk rules on confirmed facts                              | Future HELIOS phase, not these references  | Independently reviewed deterministic rules                                     | High clinical risk                                                     | Phase 5 only; not started |

Only the additive P0 changes are implemented in this phase. No visual redesign or Phase 4 workflow rewrite is justified.
