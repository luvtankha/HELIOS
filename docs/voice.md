# Voice intake

The patient-facing `/patient/listening` path uses browser `MediaRecorder` and a local audio-level visualization. With permission, it records a bounded clip, sends multipart audio to `POST /api/v1/voice/transcribe` with signed patient proof, and shows the transcript for explicit edit/confirmation. `VoiceInteraction` keeps original, normalized, patient-edited and accepted transcript fields separate, with language/provider/status metadata. The backend processes audio in memory and does not intentionally retain raw audio. The frontend offers typed text when permission, device, network or provider fails.

The local installation and example profiles now use **`SPEECH_PROVIDER=local`**. Run `pnpm speech:setup` once with Python 3.10–3.12 available (or set `SPEECH_SETUP_PYTHON` to its executable). This creates an ignored virtual environment and downloads the multilingual small model under `work/speech-models/small`. The [faster-whisper provider](https://github.com/SYSTRAN/faster-whisper) runs on CPU using int8 computation. After setup, audio is passed through stdin and decoded in memory; inference does not require an external API or keep a recording file. The worker checks actual decoded duration, rejects silence, limits concurrent work and kills stalled processes. `SPEECH_LOCAL_PYTHON`, `SPEECH_LOCAL_MODEL_PATH` and `SPEECH_LOCAL_TIMEOUT_MS` can override the defaults. Restart services after changing `.env`.

`SPEECH_PROVIDER=openai` remains available with a server-side key/model. `mock` is still supported for explicit deterministic tests, and the unconfigured environment parser retains that test-compatible default; it always returns canned text and must not be presented as recognition. English and Hindi are the active languages. A generated English recording and a 15-second Hindi reference excerpt have been exercised locally; this is not broad accent/noise/dialect evaluation. The patient must review the transcript before accepting it.

Run `pnpm speech:smoke` for real local transcription and `pnpm test:e2e:connected` for the browser path when the local provider is configured. Browser microphone access requires permission and a secure context (`localhost` works; a plain HTTP LAN address usually does not). Recording cleanup covers cancellation, navigation, delayed permission, missing waveform support, recorder errors and aborted uploads. Local transcription may take several seconds; the browser allows up to 150 seconds and offers cancellation/text input while waiting.

Upload middleware checks session ownership, multipart fields, declared/signature-level audio type, size and duration, with a rate limit. Each retry creates a separate metadata/transcript record. Confirmation is required before accepted text contributes to intake. Error states avoid inventing a transcript. See [voice service](../apps/api/src/services/voice-service.ts), [multilingual voice detail](multilingual/voice.md), and [security](security.md).
