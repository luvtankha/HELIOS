# Multilingual support

English (`en`) and Hindi (`hi`) are the only active supported languages. The shared registry/resources localize core UI and interview questions. Original language/text and detected-language metadata are retained where supported; deterministic glossary/normalization handles bounded Hindi/Hinglish/code-switching cases and display translation. Doctor language preference exists. This is not general-purpose or clinically certified translation. Other languages are not fully working; speech accuracy depends on the configured provider and has not been broadly evaluated.

See [support matrix](multilingual/support-matrix.md), [language registry](multilingual/language-registry.md), [translation](multilingual/translation.md), [voice](multilingual/voice.md), and [limitations](multilingual/limitations.md).
